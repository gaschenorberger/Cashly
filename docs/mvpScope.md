# Escopo do MVP — Cashly

## Objetivo do MVP

Entregar uma primeira versão funcional do Cashly que permita ao usuário controlar entradas e saídas financeiras de forma simples.

## Funcionalidades incluídas

- Cadastro de usuário
- Login
- Cadastro de entradas
- Cadastro de saídas
- Categorias
- Listagem de transações
- Filtros básicos
- Cálculo automático do saldo
- Dashboard básico

## Funcionalidades fora do MVP

- Recuperação de senha
- Objetivos financeiros
- Classificação automática com IA
- Insights personalizados com IA
- Importação de extratos
- Notificações

## Critério de sucesso

O usuário deve conseguir:

1. Criar uma conta
2. Fazer login
3. Registrar entradas e saídas
4. Consultar suas transações
5. Visualizar saldo, entradas e saídas do período
